# Noor Fatima: Portfolio

My personal developer portfolio, built as a cinematic, scroll-driven single page with 3D particle effects and smooth animations.

**Live:** https://noor-portfolio-eta.vercel.app

## Sections

Hero · About · Skills · Projects · Contact

## Tech stack

| Area | Technology |
|---|---|
| Framework | Next.js 16 (App Router), React 19, TypeScript |
| Styling | Tailwind CSS 4 |
| 3D / graphics | Three.js, React Three Fiber, Drei |
| Animation | GSAP |
| Hosting | Vercel |

## Getting started

```bash
git clone https://github.com/noorfatima1123/noor-portfolio.git
cd noor-portfolio
npm install
npm run dev      # http://localhost:3000
```

Build for production with `npm run build && npm start`.

## Project structure

```
app/            Next.js routes and layout
components/     Hero, About, Skills, Projects, Contact, Navbar, Footer, particle effects
public/         Static assets
```
